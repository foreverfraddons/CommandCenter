Command Center - your own fonts
================================

Drop .ttf or .otf font files into this folder.

1. Copy the font file here.
2. Quit World of Warcraft completely and start it again.
   (WoW only sees files that were there when the game started - a /reload is not enough.)
3. Pick the font:
   - Files named 1.ttf, 2.ttf ... 20.ttf (or .otf) show up on their own as "Font 1", "Font 2"...
   - Any other name: Unit Frames > Style > "Add font file..." and type the file name once
     (for example Roboto-Bold.ttf). It's remembered from then on.

Added fonts appear in the Unit Frames font list and in Command Center's own font setting.
